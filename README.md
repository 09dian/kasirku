# Kasirku - Aplikasi Kasir Laravel

Kasirku adalah aplikasi kasir berbasis Laravel yang digunakan untuk mengelola transaksi penjualan dan data pegawai.

## 🚀 Fitur

-   Manajemen Produk & Stok
-   Manajemen Pegawai & Hak Akses
-   Laporan Penjualan
-   Pengelolaan Akun Pegawai & Pemilik

## 📌 Teknologi yang Digunakan

-   Laravel 11
-   Bootstrap 5
-   SQlite
-   JavaScript (Minimal)

## 🔧 Cara Instalasi

1. Clone repository:
    ```bash
    https://github.com/09dian/kasirku.git
    ```
2. Buat database Sqlite dengan nama kasirku
